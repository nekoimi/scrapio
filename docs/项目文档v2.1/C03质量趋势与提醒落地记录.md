# C03 质量趋势与提醒落地记录

## 交付

- 采集器质量页显示最近 10 次已结束运行的页面数、正式记录数、必填字段缺失率、唯一键生成率与异常页面率。数据集归属随采集器返回。
- 指标来自持久化任务错误与成功尝试快照。必填缺失率为必填字段错误页面数/详情页面数；异常页面率为包含 invalid 或 conflict 错误的页面数/详情页面数；唯一键生成率为成功记录数/(成功记录数+必填缺失页面数)。这是任务层面的近似指标，界面明确标注计算口径。
- 三项阈值可按采集器配置，默认最低唯一键生成率 95%、最高必填缺失率 5%、最高异常率 10%。无结果和缺字段证据的采集器显示“尚无基线”。超阈值进入项目页的可点击待办；阈值修改记录审计。

- 发版后用真实页面错误校准阈值，并检查质量待办从项目页进入运行证据的路径。
