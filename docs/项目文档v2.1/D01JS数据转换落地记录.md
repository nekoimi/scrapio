# D01 JS 数据转换落地记录

## 交付范围

通用记录工作流允许在提取之后使用 `script` 节点。采集器工作台可追加、编辑和删除转换脚本，设置输入字段、输出字段与超时。每份脚本代码和契约随不可变的采集器版本保存；保存修改生成新草稿，发布前必须回归样例，历史运行引用原版本。从历史版本复制草稿时保留对应脚本和样例。

控制平面脚本只接收声明的 JSON 字段，不提供网络、文件、进程、DOM、浏览器会话或凭据接口。浏览器页面脚本需要访问页面上下文，不能作为这个节点运行；现有 `trigger.fetch.actions` 继续拒绝任意页面脚本。后续开放浏览器页面脚本须单独定义权限及返回结果。

## 契约与限制

```json
{
  "name": "normalize_title",
  "type": "script",
  "config": {
    "script": "return {...input, title: input.title.toUpperCase()};",
    "timeout_ms": 500,
    "input_fields": ["url", "title", "body"],
    "output_fields": ["url", "title", "body"]
  }
}
```

- 输入只包含声明的字段，缺字段明确失败；字段声明最多 100 项，不能重复。
- 返回值必须是完整对象，字段集合必须等于 `output_fields`。该对象作为后续节点输入，最终仍需通过数据集类型、必填与唯一键校验。
- 代码最多 64 KiB，保存定义时检查语法；超时最多 2000 ms，默认 2000 ms；单次输入/输出各最多 512 KiB。正式运行的取消上下文传入脚本执行器。
- 输入在沙箱内由 JSON 重新构造，不暴露调用方的 Go 对象。JS 修改 `input` 不会改写调用方的数据。
- 沙箱的大小限制控制 JSON 输入输出，不是进程级内存配额；当前仅适用于自用或小团队可信维护者编写的转换脚本。

## 样例与追溯

预览、全量样例回归、版本比较和正式执行使用相同的脚本转换路径。回归面板展示 script 步骤、转换后的字段或错误。预览不写记录，也不触发插件。脚本运行失败与契约失败阻止该页面记录批次提交；现有阶段快照记录为提取与转换链失败。

脚本版本由“采集器版本 ID + 节点名”标识，暂不引入可独立更新的共享脚本库，避免发布版本的行为随外部脚本修改而变化。
