# C02 字段诊断与版本比较落地记录

## 交付

- 样例预览和回归展示字段规则位置、选择器、匹配数、原值、转换值及错误。提取失败会保留当前节点的诊断；数据集准备失败也会在步骤中显示。字段诊断与正式执行共用提取器及完整的节点链。
- `POST /api/v2/workflows/versions/compare-samples` 对同一采集器的两个版本使用同一批样例做离线回放；返回逐字段、结果状态、发现链接及预计保存决策的差异。每次最多比较 50 个样例，不写正式记录。
- `POST /api/v2/workflows/versions/rollback` 改为把历史定义和样例复制为新草稿。草稿需回归并显式发布；历史发布版本与旧运行引用不会改写。复制草稿与发布分别记录审计事件。
- 采集器工作台展示字段诊断、版本样例差异与“复制为草稿”操作。

## 验证

- `SCRAPIO_TEST_DEV_C02=1 go test -timeout 120s ./internal/repo/workflow_repo -run TestDevRecordTemplatePublication -count=1` 在开发 PostgreSQL 验证同定义与变化定义对比、草稿样例复制和旧运行版本引用。
- 字段诊断单元测试覆盖缺失字段定位和选择器匹配数。`go test -timeout 120s ./...`、前端 `npm run build` 与 `git diff --check` 通过。

## 发版验收

使用历史失败页面从运行中心进入采集器，调整草稿规则；对比旧版本与草稿在同批样例上的字段和记录差异，确认回归、发布和后续运行。浏览器页面与窄屏交互随发版检查。
