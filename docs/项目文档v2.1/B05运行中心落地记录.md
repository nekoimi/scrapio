# B05 运行中心落地记录

## 本轮交付

- 运行中心按原型组织为运行列表、页面任务树和页面检查面板。运行详情汇总访问、发现、候选、新增、变化、未变、失败、受限数量，并展示部分成功、失败和受限结束的说明与持久化终止原因。
- 页面任务每次读取 100 条，任务尝试每次读取 20 条；可查看阶段错误、请求和结果快照、历史文档原文与截图。切换运行或任务时，过期请求不会覆盖当前页面。
- 从页面检查面板进入对应采集器的草稿样例区。存在文档时预填历史文档 ID、页面角色和 URL；无文档时预填实时来源。若只有已发布版本，先创建编辑草稿，再由用户保存样例并预览。
- 获取、文档保存、发现、提取和持久化失败留下机器可读的阶段快照。候选和保存决策从持久化尝试及观察记录重建；历史运行无需重新执行。

## 验证

- 开发 PostgreSQL `get_magnet_dev`：`SCRAPIO_TEST_DEV_B05=1 go test -timeout 120s ./internal/repo/task_repo -run TestDevRunInspection -count=1`。隔离用例覆盖 105 个任务的两页读取、重试尝试排序、成功/失败/受限页面、发现数、候选数、保存决策和终止原因；用例清理临时数据。
- `go test -timeout 120s ./...` 通过；`web` 目录 `npm run build` 通过。前端构建仍输出项目原有的 Vite CJS 与 Sass 弃用提示。
- 部分成功、无结果失败、受限结束的状态聚合由 `RunSummary` 用例覆盖。运行中心以既有持久化状态呈现，不重新推断运行状态。

## 发版验收

用户发版后，用真实列表、详情和浏览器页面检查运行中心：核对部分成功、失败与预算截断的指标和证据；从失败页面进入草稿，保存历史文档样例、预览、发布并复跑；检查窄屏布局及截图显示。B05 开发库用例不代替这些真实环境验收。
