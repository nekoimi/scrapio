# C04 维护与存储治理落地记录

## 交付

- 采集器增加负责人；新草稿保存变更摘要。工作台传入所基于的版本 ID，保存时锁定采集器并检查最新版本，检测到其他人已创建新版本会返回冲突提示。版本列表展示摘要，负责人修改记录审计。
- 新增原文和截图各 10 MiB 的保存上限，超限任务明确失败。既有 HTTP 获取上限保持生效。
- 文档保留期通过 `RETENTION_DOCUMENT_DAYS` 配置，默认 `0`，即关闭自动清理。启用后每日最多清理 1000 个超过期限的孤立文档。`GET /api/v2/documents/retention/preview?days=N` 和采集器质量页显示候选数、保留数及候选字节数。清理会跳过样例、记录观察和存活任务引用的文档；外键也阻止并发删除有样例引用的文档。数据库删除与截图资产删除同一语句完成。
- 工作流发布边界继续拒绝未实现的凭据解析；当前执行器只接收页面动作，不接受定义内明文凭据或会话字段。现有配置输出有脱敏测试。浏览器服务自身的日志与会话管理仍需在真实环境联调时检查。

- 生产启用清理前先备份、查看保留预览并确认容量与期限。发版后核对真实浏览器日志和截图大小、窄屏工作台及维护操作。
