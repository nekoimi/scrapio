# D02 插件订阅落地记录

## 实现范围

- 数据集级和采集器级显式订阅，默认停用。事件限定为 `record.created` 与 `record.updated`，订阅绑定当前 Schema 的标量 URL 或字符串字段。
- 正式记录的写入事务同时创建持久化插件任务。只有事务提交后后台 worker 才能领取；一批记录失败时记录与任务一并回滚。`unchanged`、重复幂等写入、历史迁移、样例预览及任务文档重放不派发。
- 插件任务扩展记录、观察、数据集、采集器和订阅来源字段，旧 `resource_id` 任务保持兼容。新任务复用已有领取、租约、重试、取消及监控；任务输入冻结 URL、记录快照和运行来源，任务结果保存在插件任务输出。
- 当前可订阅插件为配置启用的 `cloud-driver` 和 `aria2`。云盘插件以订阅观察为外部幂等键；通用记录的云盘完成结果写入插件任务，不修改记录。其他插件必须显式声明支持记录事件才可订阅。
- 采集器页增加订阅配置、适用范围和最近任务；发布确认列出当前启用的外部副作用。订阅配置独立于不可变规则版本，修改后对后续正式运行立即生效。

## 验证

- `go test -timeout 120s ./...` 通过。
- `SCRAPIO_TEST_DEV_D02=1 go test -timeout 120s ./internal/repo/record_repo -run TestDevD02SubscriptionDelivery -count=1` 在 `get_magnet_dev` 通过，覆盖新增、更新、未变化、重复写入、重放、禁用订阅和批量回滚；测试仅清理自身数据。
- `web` 的 `npm run build` 通过，仍有项目既有的 Vite/Sass 弃用提示。

## 发版联调

实际云盘、aria2 外部服务和浏览器采集联调留待发版环境。`aria2.addUri` 本身未提供与队列幂等键等效的服务端去重；请求已成功但响应丢失时，任务重试仍可能创建重复下载。上线启用前应在真实服务验证此行为。
