# C01 连续运行与检查点

状态：2026-10-10 开发收尾。真实迁移、网站/浏览器、事务/中断和 UI 验收保留发版。依赖 B06/B07，后续 C02 调度、C04 安全重试与完整运行中心。

## 产品操作

1. 在记录设计器配置下一页类型：链接导航、翻页按钮或加载更多，设置最多列表轮次（1～100）和动作后等待（0～10000 ms）。HTML 本页/累积列表记录上限可配 1～200；加载更多应覆盖累积列表，达到上限会标记截取。
2. 保存、试采并重新发布。试采保持最多两轮和原小预算，有限覆盖需显式确认。旧版本 `max_pages=2` 继续最多两轮，修改草稿不会改变发布版本。
3. 在版本正式运行中选择预算：5～900 秒、1～100 文档、1～1000 去重后候选、0～100 详情。可使用连续采集预算预设，再重新确认范围/真实网站动作及正式写入。保留发布时小预算作为默认，预设不会自动执行。
4. 在正式运行面板或运行详情查看保存的检查点、累计范围和停止原因，打开对应真实列表文档。检查点按事件序号由新到旧分页，刷新读取最新状态，加载更多读取更早状态。

正式运行不是无限循环。页面内容最多 1 MiB、累计文档/诊断最多 8 MiB、输出预判最多 2 MiB、正式摘要最多 8 MiB。增加时间/页数不绕过这些保护。JSON 入口当前保持单次 HTTP 请求，JSON cursor/offset 分页不在此实现。

## 循环和停止语义

| 情况 | 结果 |
| --- | --- |
| 没有或禁用下一页 | `NO_NEXT_PAGE`；其他验证通过可正常完成 |
| 后续轮没有记录 | `EMPTY_PAGE`；保留空页证据，先前有效候选可以提交 |
| 第一轮零有效候选 | 不能假成功；最终输出失败且不写正式记录 |
| 记录集合/详情 URL 重复，即使页面装饰不同 | `REPEATED_PAGE`，limited |
| 下一链接指向本步骤已经访问的 URL | `REPEATED_URL`，limited；去除 fragment，保留 query |
| 本轮无新增输出候选且仍有下一入口 | `NO_NEW_RECORDS`，limited，不推断网站已完全采完 |
| 规则轮数或文档/输出候选/详情预算已达边界 | 明确预算停止，limited，下一动作不派发 |
| 截取/字段错误/同键不同值 | 截取明确受限；字段/冲突仍阻断正式写入 |
| 动作未知、跨域、返回列表不匹配、时间/内容上限中断 | 停止并保留证据；未验证完整结束的批次不提交 |
| 用户取消、服务停止、租约失效 | 停止并保留最后检查点，不自动重放 |

文档预算统计提取的列表/详情文档，详情返回检查不计提取文档；网站动作/加载次数与文档数不同。每页详情上限仍 1～5，运行总详情可到 100。配置下一页以真实动作执行，不能仅提取 next URL 假装翻页。

按钮/加载更多允许来源 URL 不变，记录集合必须推进。`wait_ms` 是显式动作后等待，页面请求较慢时需调整；尚未出现新内容会保守 limited，不假报完整覆盖。与旧 `click` 使用同一动作能力，独立 `load_more` 类型表达累积列表语义。

跨轮相同规范键和输入值跳过重复输出，但保留原始文档全部提取诊断及 `output_indices`。同页重复、跨轮同键不同值继续交给共用输出预判，不通过去重掩盖冲突。持久写入重新读取文档并复用索引，保存的本地来源索引不因去重而漂移。相同详情 URL 在同一步骤内只访问一次，下次正式运行仍产生新的来源观察；跨次运行依赖既有逻辑表唯一键/更新策略。

返回列表时比较 URL、提取记录/详情路径和下一目标，保留加载更多状态；仅页面装饰变化可继续。返回到丢失累积记录的同一 URL 会失败，不能继续使用旧列表证据派发动作。

## 检查点和恢复边界

新增表 `v22_run_checkpoints`，迁移 `2026_10_10_005`。检查点由 worker 在持有有效 lease 时保存，与该事件共事务，外键绑定同运行/attempt/真实列表文档。运行 owner 决定读取权限，游标只能引用同一运行。

`GET /api/v3/runs/{run_id}/checkpoints?limit=25&cursor=<checkpoint_id>` 返回 `items/next_cursor/has_more`。limit 1～50，按事件序号降序；行中 ID/attempt/sequence/时间为字符串，`checkpoint_json` 是完整精确载荷。旧运行不会补造检查点。

| 状态 | 能证明什么 |
| --- | --- |
| `page_captured` | 本轮列表文档已保存；详情或输出范围可能尚未处理完 |
| `page_complete` | 本轮配置预算范围处理结束，下一页还没派发；有限覆盖仍看运行警告 |
| `action_pending` | 持久日志位于翻页/详情/返回动作派发前；不能仅凭此状态确定动作是否发生 |
| `awaiting_page` | 翻页动作与等待已得到成功回执；下一轮列表文档尚未保存 |
| `stopped` | 循环停止位置与原因已记录，不代表正式写入已提交 |

载荷包含步骤、列表轮次、文档 ID/hash/来源、下一目标、停止原因及累计文档/列表/候选/详情/重复候选数。运行摘要保留最后检查点，活动运行可显示当前已保存范围；记录计数只有 B06 终态写入成功才显示已提交。

本阶段没有自动续跑或手动重放 API。服务中断/lease 过期后保留最后诊断并结束旧 attempt；未知点击、HTTP POST、登录与累积 DOM 不能从一个 URL 安全恢复。C04 再定义固定版本、确认范围、动作授权和恢复条件。此处检查点用于准确识别完成到哪里和哪次动作未知，不伪装已经具备恢复执行能力。

正式记录仍沿 B06 在有效结束时整批原子提交，当前不是每页增量提交。安全分页预算边界可提交已验证候选并保留 limited；取消、未知动作、中途失败和超时没有终态输出预判时不写本批记录。长运行中断后有文档/检查点但可能没有正式记录，界面明确区分。

## 执行边界与资源

浏览器会话 TTL 取运行预算加余量（上限 600 秒），操作前临近到期续期，并确认原 page_state/URL 未改变。续期不自动采用外部改变的页面状态。没有修改浏览器 protobuf 或要求新服务动作；沿用已有导航/点击/等待/快照/心跳接口。

正式 worker 仍单实例顺序执行，最多三个活动请求；排队超过 45 分钟结束，以适配最长 15 分钟任务。写入事务超时扩大至 30 秒，数据库 lease 隔离与提交前重新检查仍生效。服务重启不自动重放正在运行的任务，排队任务保留。

## 验证与回退

短单元检查覆盖三轮实际动作、累积列表重复/无新增、空页/重复 URL、停止预算、详情 URL 去重/列表返回、取消/未知动作、冲突保留、索引来源和大整数。Go API/worker/repo/migration 编译、Vue 组件及脚本检查与 OpenAPI 引用检查完成，不运行真实数据库或浏览器长测。

真实迁移/租约并发、慢站点、长运行心跳、加载更多布局、UI 和实际写入请按主待办 C01 验收清单发版核对。开发状态不等于真实链路已验收。

回退可以关闭连续运行 worker/入口，已有检查点表可保留。回退旧二轮版本不会自动处理包含 `load_more` 或较大预算的新运行，应先停止这些运行，再回退；不能把新定义静默降级成旧两轮计划。
