## 独立应用外壳的先行实现

- `/#/app/home` 是独立 Vue 路由与导航，沿用现有登录令牌，登录后默认进入新首页；左下角显式提供旧版入口。服务端 `/app` 和 `/app/**` 深链会重定向到对应 hash 路由，保留查询参数。首页仅调用 `/api/v3`，不读取 v1/v2 数据、旧磁力记录或旧方案计数。
- `GET /api/v3/me` 返回已认证用户的 ID/用户名；`capabilities` 明确返回交互浏览器不可用；`home` 返回 `pending`，避免将旧数据混入新首页或把未建立的数据域显示为零条数据。当前 URL 创建草稿入口可用，浏览器编辑和正式采集尚未开放，其他一级页面仍显示建设状态。
- `v22_collectors` 是独立的 v2.2 草稿模型，支持 URL 创建、游标分页列表、读取、revision 更新、归档和创建/复制幂等；API 返回字符串 ID、定义以 JSON 对象传输，不引用历史 workflows/datasets。草稿更新会同步定义与方案顶层入口 URL、返回保存变更摘要；结构检查将结果绑定到草稿 revision，后续内容修改会将状态显示为过期。复制只复制方案定义，不复制任何运行或记录实体。前端已接入首页 URL 创建、分页方案列表、复制、JSON 自动/手动保存、冲突时显式加载服务器版本、撤销未保存修改和结构检查状态。
- 这是 A01/A02 的先行实现，不算阶段放行：后续新数据域、真正的首页聚合、浏览器能力协商、自动保存端到端/冲突实测、反向代理和 Docker 环境深链验证仍待后续任务。
- 验证：Go API 包测试通过，前端 `pnpm build` 通过；本机浏览器仓库 `DEBUG=false .venv/Scripts/python.exe -m unittest tests.test_browser_job tests.test_v22_interaction_spike` 共 5 个用例通过。浏览器子进程仍有一次退出时的 `ResourceWarning`。

## 协议方向与未决项

保留旧 `Execute`，拟增加 editor 专用服务或独立协议版本。控制平面持有用户/草稿授权与 session 映射；浏览器服务维护真实 tab 与页面状态。浏览器操作分为**只检查**（inspect/locator-check）和**真正执行**（navigate/click/input/wait/scroll）；每次请求带 session_id、page_state_id、command_id，过期状态返回结构化错误。画面帧带相同 page_state_id，不能将旧帧坐标作用到新页面。

阶段 0 初始原型仅支持 navigate/click/scroll；2026-10-09 A03 已接 editor.v1 gRPC、会话所有权/TTL/配额管理。命令原语仍只缓存**成功**回执，尚未作为 A04 正式动作 API 对外开放。实际网页动作可能在返回错误前已经发生；正式服务必须先定义这种不确定结果的查询/恢复策略，不能自动重试可能有副作用的命令。

本机缩放测试使用页面 CSS zoom 和实时 DOM 坐标，尚未验证压缩画面在前端显示缩放后的坐标换算。初始原型的 `page_state_id` 只随显式命令变化；A03 收尾已加入 DOM observer、文档标识、URL/滚动/viewport 状态探测，截图前后校验版本。canvas/动画逐像素变化和前端点选坐标换算仍需后续任务验收。

需要验证的决策：

1. 截图帧的刷新频率、压缩、视口/缩放/滚动坐标映射，是否采用 SSE+按需帧、WebSocket 或其他传输。
2. DOM 命中是否通过 CDP/DrissionPage 稳定取得元素边界与相对选择器；跨 iframe、Shadow DOM 的处理边界。
3. session 生存期、最大并发、超时、断线清理、重新连接与动作去重；恢复时重放可能有网页副作用的动作必须由用户决定。
4. 远程浏览器管理器启动、健康、断开与资源回收的真实联调。

用户确认暂时没有可连接的远程环境，先使用本机浏览器验证。本机 `scrapio-browser` 未配置 `.env` 的远程 CloakBrowser-Manager 连接；远程会话与网络传输的 002 验收保留未完成，其他不依赖远程连接的工作可推进。

以上未通过前，工作台原型只能用于交互走查，不能将 002 标记为完成。
