## 1. 目标与问题来源

工作台应支持一条顺畅的操作链：打开页面 → 滚动浏览 → 选择记录 → 配置字段 → 验证规则 → 保存预览。用户在命名字段、核对候选和保存草稿时，选择内容不应因后台刷新或临时忙碌而消失。

2026-10-11 首轮实施前的实现检查所得（用于说明优化原因，当前交付状态见第 8 节）：

| 现象 | 当前机制 | 带来的问题 |
| --- | --- | --- |
| 网页区域无法直接向下滚动 | 展示 PNG 的 `<img>`，没有绑定滚轮；滚动通过动作表单执行 | 管理界面滚动与远端网页滚动混淆，页面下方内容难以访问 |
| 画面更新有延迟 | 会话 SSE 每 3 秒检查状态；首次打开及 `page_state_id` 变化时拉取截图 | 用户操作后可能看到旧画面；动画、Canvas 变化不一定刷新 |
| 新图到达时高亮消失 | 获取新截图后调用 `clearFrame()`，同时清除高亮 | 同一页面刷新也会打断视觉反馈 |
| 选择状态自动清空 | 选择组件将页面状态、可用性、模式、目标和 `blocked` 变化统一处理为清空 | 自动保存、动作忙碌、短暂断线都可能使未完成选择消失 |
| 动态网页频繁使选择过期 | 浏览器页面令牌覆盖整页 DOM 属性/文本/节点变化、滚动及视口变化 | 广告、倒计时或异步内容也可能使旧令牌失效 |
| 无操作时也弹出错误 | 鼠标悬停发起元素检查；组件虽忽略悬停失败，全局请求拦截器仍弹错误 | 鼠标经过空白或范围外元素便可能反复干扰用户 |
| 错误信息无法指导恢复 | 浏览器检查将多种输入/元素/定位失败归为 `INVALID_ARGUMENT` | `Invalid selection, reference, or locator` 无法区分范围错误、元素消失与语法错误 |

这些是代码机制分析，不表示每条机制都已通过真实网站复现。具体报错仍需以请求 ID、检查类型和浏览器响应确认，不能全部归因于页面版本变化。

## 2. 产品行为与边界

采用“浏览时及时更新，点选后保留配置”的行为：画面跟随远端网页，右侧选择面板保留用户编辑；失效的是旧高亮、坐标和验证证据，而不是字段名称和候选规则。

- 截图是真实浏览器画面，不是可直接交互的 DOM，也不是视频。画面更新状态应可见。
- 暂停画面只暂停展示刷新，不冻结远端网页；不能因此认定旧坐标仍有效。
- 点选只检查元素；点击、输入、导航等网站动作保留现有明确确认与命令回执约束。
- 滚动是远端网站操作，可能触发懒加载。滚动入口说明该影响，不将滚动伪装为只读检查。
- 本轮不自动点击详情、不自动翻页、不接入 AI，也不改试采、发布和正式写入边界。
- 过期证据不能用于“确认使用”或执行动作；必须在当前页面重新验证。重新验证不自动执行动作。

## 3. 网页视口与操作工具栏

网页区顶部固定显示：当前页面标题/地址摘要、后退、刷新网页、向上滚动、向下滚动、更新画面，以及适应宽度/原始比例。能力不可用时禁用并解释原因，不展示可点击但无效的按钮。

“刷新网页”执行网站 reload，可能重新加载数据；“更新画面”仅获取当前状态与截图，两者分开命名。保留浏览、点选、录制模式；点击截图的行为遵循当前模式及确认边界。

网页区形成独立视口，左侧步骤和右侧配置有各自的内容滚动。管理页滚动不会被当作远端滚动。原始比例导致截图超出可视区域时，可在本地平移查看，坐标映射必须使用图像实际显示范围；本地平移和远端网页滚动明确区分。

### 3.1 滚动按钮先落地

- 复用既有 `scroll` 命令，以有界 CSS 像素增量执行；默认建议每次约 600px，实际由当前协议限制。
- 通过已有动作队列串行执行；待确认请求、动作结果未知、会话失效时禁止继续派发。
- 滚动完成后根据回执获取新状态和截图；画面更新前暂不接收截图点选。
- 浏览和点选模式下滚动仅用于浏览，不加入草稿步骤。录制模式下通过明确的“记录滚动”选项决定是否加入，默认关闭。
- 截图只有 PNG 像素尺寸时不反推网站 CSS 滚动距离；按钮增量与视口坐标转换分别处理。

### 3.2 再接入滚轮

- 只在光标位于网页视口且远端交互可用时消费滚轮；侧栏、工具栏和页面其他区域保留原生滚动。
- `Ctrl`/`Meta` + 滚轮不转成远端滚动，保留浏览器缩放操作。
- 合并约 100～150ms 内的增量，规范 `deltaMode`，限制单次距离；建议待执行增量只保留一个合并槽，不建立无界队列。
- 只有上一条命令已确认并获得可用画面后才继续派发。网络错误或未知结果停止队列，查询原回执，不用新命令 ID 自动重发。
- 内部滚动容器支持需另行扩展协议；首轮按钮只保证页面主滚动。滚轮不能处理某区域时给出明确提示，不声称所有嵌套容器已支持。
- 触摸、PageUp/PageDown 和键盘滚动作为后续适配；滚动按钮是首轮可访问的替代入口。

## 4. 截图更新与展示

### 4.1 第一轮：及时刷新和平滑替换

保留现有 SSE 与 PNG 接口，动作完成后立即拉取状态及截图；支持“更新画面”。SSE 继续承担会话/页面状态通知，不先增加一套重复的高频状态轮询。

前端集中管理画面请求：

1. 同一会话只保留一个在途截图请求；新需求合并为一次待刷新，不叠加请求。
2. 记录会话身份、请求序号和页面令牌；路由切换、会话关闭或页面版本变化后，迟到帧不能覆盖当前画面。
3. 新图解码成功后再替换旧图，随后释放旧 object URL；请求失败或解码失败保留旧图并明确标为过期。
4. 替换画面不调用“清除选择”。高亮属于特定画面，只有匹配新帧及有效验证时才显示。
5. 截图开始/结束两次状态校验失败时不发布该帧；短暂页面抖动采用有限合并重试，持续变化显示“页面持续更新，暂时无法点选”，不能无界重试。
6. 旧图、更新中、会话不可用时禁止按截图坐标派发点选或点击；提供恢复/更新入口。

### 4.2 当前策略：编辑优先、按需更新（UX10）

默认关闭持续观察，沿用 SSE 与心跳提供状态，不对未变化页面定时截图。首次打开/恢复、动作完成与手动更新仍取得新画面；SSE 检测到页面/文档/DOM或画面版本变化时，保留配置并使旧画面失效，待空闲后合并更新。

| 工作台状态 | 当前策略 |
| --- | --- |
| 页面状态未变化 | 不重复截图 |
| SSE 检测到变化 | 一份待更新意图，600ms 合并窗口；后台截图启动至少间隔 3 秒 |
| 点选、表单焦点、核对当前选择/数据预览、未保存规则 | 暂缓后台截图，明确提示变化和重新验证；可主动更新 |
| 动作完成或用户点击更新 | 优先更新，消耗已满足的后台需求；同一版本在途请求/解码共享结果 |
| 用户开启持续观察 | 基础间隔 5 秒，按截图耗时降低频率；交互暂停，鼠标活动预留 1 秒空闲窗口 |
| 标签页隐藏/离开编辑阶段 | 暂停；返回编辑区先同步状态 |
| 更新失败 | 按需模式不自动重复失败请求，保留手动恢复；连续观察或新变化继续遵守 10～15 秒退避 |

旧帧和更新期间的点选/点击禁用保持严格。短暂更新仅显示小状态点，超过 800ms 显示更新文字；首次加载、失效和断连立即提示。状态区保持高度，正常后台更新不反复切换黄色过期外观。只延迟提示，不延迟安全状态。

UX10 首轮继续 PNG；UX12 在支持新能力的浏览模式启用 CDP 连续预览，点选、录制与降级仍采用本节 PNG 策略。原 UX06 的 400/1800ms 属历史实现。编码调优和内部滚动容器仍待 UX08 技术验证。

## 5. 选择与验证生命周期

选择状态拆为：未选择、检查中、已验证、待重新验证、会话不可用。`blocked` 表示临时不能操作，不再等同于“删除选择”。

| 事件 | 保留内容 | 失效内容/下一步 |
| --- | --- | --- |
| 保存中、动作检查中 | 元素摘要、候选、字段名、提取类型 | 禁用冲突操作，结束后恢复；不清空 |
| 同状态截图刷新 | 全部选择与配置 | 只有确认画面一致时保留高亮 |
| 页面令牌变化/滚动 | 规则、命名、范围和编辑输入 | 隐藏旧高亮，停用旧 element ID/坐标/命中证据，提示重新验证 |
| 元素暂时消失 | 规则及用户输入 | 标记无匹配，不自动换成另一元素 |
| 会话暂时断开 | 本地编辑及选择摘要 | 禁止远端操作，恢复后重新验证 |
| 导航到新文档/重新打开会话 | 未保存配置保留为本地草稿 | 旧选择标为过期，不自动跨文档恢复元素身份 |
| 切换记录/字段/详情/下一页目标 | 每个目标的未完成配置，范围变更需标记依赖失效 | 不静默丢失；返回后核对范围并重新验证 |
| 用户取消选择/确认替换 | 已加入规则和其他字段配置 | 清理对应临时选择，不连带清空整个编辑器 |

选择面板提供“重新验证”“重新点选”“取消选择”。重新验证使用当前页面的定位器与范围；旧页面元素 ID 不直接复用。命中集合变化时展示新样本与变化提示，由用户核对后确认，不能自动认定为原元素。

准备点击动作比提取规则更严格：即便定位规则在新页面重新命中，也不能继承旧点击确认；应重新准备并确认动作。所有结果继续校验会话、目标、请求序号、页面令牌与草稿 revision，迟到响应不覆盖较新的编辑。

已加入规则的保存、预览、试采和发布使用原有流程。保留本地选择不代表已保存到数据库，不代表通过当前页验证或可以发布。

## 6. 悬停、错误与恢复反馈

### 6.1 检查请求协调

- 点击优先于 hover；用户开始命名或修改选择面板后暂停 hover。
- hover 保留节流和最新一次请求；取消/丢弃迟到响应，不修改明确选中的元素、规则和字段名。
- 保存/动作/滚动期间暂不派发新检查，必要时提示页面更新中。
- 暂停 hover 只停止悬停检查，不能停止明确点击后的验证。

### 6.2 错误分层

Go 和浏览器侧返回稳定错误码、可恢复提示与请求 ID。UX02 已使用既有 `error_code` 落地具体检查错误码，见第 10 节；继续兼容旧服务的 `INVALID_ARGUMENT` 和 `STALE_PAGE_STATE`，不通过英文 message 字符串猜测业务类型。

| 语义 | 前端反馈 | 是否保留配置 |
| --- | --- | --- |
| 点位无元素/悬停空白 | hover 静默；明确点击提示请选择可见元素 | 是 |
| 字段在记录范围外 | 面板提示选择记录内部字段或调整范围 | 是 |
| 元素引用已失效 | 提示重新点选或按当前规则验证 | 是 |
| 定位器语法错误 | 定位规则旁显示语法提示 | 是 |
| 页面版本已变化 | 标记待验证，协调更新画面 | 是 |
| 页面忙碌 | 状态栏短提示，等待当前操作完成 | 是 |
| 会话失效/断开 | 会话级提示与恢复/重新打开入口 | 是，但远端证据失效 |
| 认证或访问权限失效 | 保留现有认证处理，停止操作 | 不自动清空本地输入 |

浏览器检查接口引入明确的局部反馈选项，全局拦截器不再对已由工作台处理的失败重复弹窗。hover 无匹配不是应用级异常；认证失效仍走全局认证流程。真正的服务故障必须在状态栏可见，不能因“静默请求”被吞掉。

浏览器脚本不再用一个 catch 把所有失败压成相同 message；区分输入校验、范围、元素引用及定位语法。日志保留操作类型、请求 ID、错误码与内部原因，不向 UI 泄漏原文、凭据或不受控的异常堆栈。

## 7. 页面版本与协议演进

### 7.1 首轮沿用当前令牌

继续用 `page_state_id` 校验截图、检查和命令。任意令牌变化都使旧证据失效，但本地选择配置保留。此阶段不能通过关闭 MutationObserver、忽略版本冲突或扩大过期时间解决体验问题。

### 7.2 UX07 已实现的三类状态（保守验证边界）

| 状态 | 拟议含义 | 使用边界 |
| --- | --- | --- |
| 文档身份 | 导航/重载或文档整体替换 | 元素引用不能跨文档复用 |
| 画面状态 | 截图帧、视口、滚动位置、像素比 | 坐标、高亮及点击依据必须匹配 |
| DOM/规则验证状态 | DOM 变化与定位器命中证据 | 决定规则是否需重新验证 |

拆分状态后，滚动使旧坐标失效，但不删除规则；无关 DOM 变化不会直接删配置。是否可继续确认规则须通过当前元素/定位器的验证证据决定，不能仅凭文档未变化认定有效。

UX07 通过可选 `EditorSessionResponse.state_json` 返回扩展；PNG 接口以 `X-Scrapio-Frame` JSON 响应头携带同次捕获的帧序号、文档身份、页面令牌、CSS 视口尺寸、图像像素尺寸、滚动偏移、像素比与捕获时间。会话/SSE 与检查 JSON 返回 `state`，不拼接不同版本来补全截图。`editor.state.v1` 能力探测与 `supports_frame_metadata` 控制扩展说明；旧服务保留现有严格校验并明确降级。细节见第 13 节。

会话事件只推送新状态与恢复信息，不替代动作回执。动作仍须有幂等命令 ID、版本校验和未知结果查询；SSE 重连不能触发命令重放。

## 9. 验收与检查策略

先做短时、有超时边界的组件/协议验证；不反复运行耗时全量测试。真实浏览器目标、部署与性能验证独立记录，由发版测试完成；mock 不计为真实站点通过。

| 场景 | 必须验证的行为 |
| --- | --- |
| 豆瓣 Top250 或其他无登录长列表 | 滚动到视口下方，截图更新后能选中正确记录/字段；不自动翻页或访问详情 |
| 选中后停留、命名、保存 | 字段名、候选与提取类型不丢；保存中只禁用冲突操作 |
| 动态 DOM/广告/倒计时 | 配置保留；旧证据明确失效，重新验证不自动替换目标 |
| 滚动、导航、返回 | 旧高亮和坐标停用；规则保留，重新点选/验证后可继续 |
| hover 空白/范围外、错误 CSS | hover 不弹全局错误；明确点击或验证有具体局部提示 |
| 慢截图、迟到响应、快速切换会话 | 旧图留存且不可误操作，晚帧不覆盖新帧；选择响应不覆盖新编辑 |
| 断线与动作结果未知 | 保留配置；查询原回执，不自动重发滚动或点击 |
| 浏览/点选/录制切换 | 点击与滚动行为清楚；默认浏览滚动不写草稿，录制结果按回执保存 |
| 1440×900、1280×800、窄屏与高像素比 | 独立滚动、缩放、坐标和高亮一致；窄屏有按钮及 DOM 树替代入口 |
| 标签页隐藏与持续刷新 | 隐藏停止抓帧；返回先同步；单会话无截图请求堆积，服务无异常负载增长 |
| 旧浏览器服务 | 未支持的新协议功能明确禁用/降级，保留原严格版本检查 |

最低可用门槛：能浏览长页面；未完成配置不自动消失；错误不反复弹窗；过期画面/选择不会执行错误动作。先达到这四项，再按实测决定连续画面的刷新频率。

### 16.2 规则后台复核

新增只读 `POST /api/v3/browser-sessions/{session_id}/locator-rechecks`，输入包括上次的 `document_id`、定位/范围和 `previous_fingerprint`。浏览器只在同份文档重取当前令牌、执行定位并校验前后状态；禁止坐标、元素引用及帧序号。导航、关闭、未确认动作及身份失配仍拒绝。

范围/目标的节点身份、节点类型、关键属性（href/src/srcset/role/type/disabled/aria-disabled/formaction）、baseURI 与截断情况组成指纹。普通文本、样式或无关节点变化不自动改变该指纹；样例读取当前值。匹配一致时静默更新定位证据，保留名称/提取方式/草稿；不恢复旧元素引用、坐标或真实点击确认。范围、目标身份或关键链接变化时展示前后样例，用户确认新命中才可继续使用；零匹配/截断不可确认。

复核由状态变化触发，600ms 合并且启动间隔至少 3 秒；编辑定位、切换目标/会话、取消或迟到响应不能覆盖当前配置。持续变化导致复核期间版本改变时保留输入并等待再次复核/手动验证，不忽略 MutationObserver，不保证高频 DOM 页面能稳定点选。

### 16.3 传输与运行边界

## 18. UX14 修复记录：文字所在链接（2026-10-11）

问题：点击 `<a href="…"><span>标题</span></a>` 的文字会选中 `span`。把提取内容改成链接后，原规则仍匹配 `span`，它自身没有 `href`，因此链接预览与运行结果为空。

浏览器检查新增可选返回字段 `enclosing_link`，仅描述选中元素最近的 `a[href]` 祖先；祖先须位于当前记录范围内且不能等于范围根，不跨 iframe/Shadow DOM，不提供遮罩元素。文字选择本身保持原元素，界面提供“选中所在链接”。切换字段提取内容为链接，或重新点选已有链接字段时，前端重新检查祖先引用并验证其定位规则，保存的字段指向真实 `a`；原有运行提取逻辑继续读取该元素的 `href`。重新点选仍保留字段名、稳定标识及清洗设置。

定位检查新增可选 `link_sample_values`，按 `document.baseURI` 解析相对链接；链接字段、详情和链接翻页目标展示地址样例，后台复核差异也展示地址。空地址、非法地址、非 HTTP(S) 协议、含用户密码或超预算地址不显示为可用链接；读取样例不访问目标。已失效引用不能用于祖先点选，仍需重新点选/验证。
