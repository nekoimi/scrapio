# 受控转换与 JS 扩展 O5-05 实施与验收记录

> 2026-10-14：开发收尾；真实页面、正式落库和进程恢复验收仍待 O5-R。首版协议为 `co.transform.v1`，复用已有 goja 依赖，无新增数据库迁移或浏览器协议。

## 1. 用户入口与执行位置

独立采集器工作台的主输出、附加端口字段提供「字段提取后转换」。任务编辑器的输入连接在映射表下提供「映射值转换」。默认关闭，旧定义行为兼容。使用模板的 Element Plus 控件配置输入类型/数组/null/空值、表达式及样例，预览不会执行采集或写正式数据。

| 位置 | 顺序 | 目标契约 |
| --- | --- | --- |
| `output.mapping[].transform` / 附加端口 | 定位、提取、clean → 转换输入校验 → 表达式 → 输出校验 → 身份 → 保存/派发 | 该输出字段 Schema |
| `edges[].transforms.<input_key>` | 原值过滤、数组展开、binding → 转换输入校验 → 表达式 → 下游校验/Prepare → 工作项 | 下游输入 Schema；batch 为数组元素契约 |

每个表达式只读取当前 `value`；不修改上游输出、其他字段、分页、动作或保存绑定。未命中的字段仍按已有缺失/默认值处理，输出默认值直接通过目标契约，不执行转换。HTML提取可先按转换输入Schema做基础类型转换；离线样例应填写符合该输入Schema的JSON值。对JSON字段提取仍沿用原有类型处理。

示例：评分输入 string，目标 number，表达式 `Number(value.replace("分", "").trim())`，样例 `{"value":" 9.2分 ","expected":9.2}`。连接可用 `"https://example.com/subject/" + value` 从标识生成URL；转换成功仍可能因目标访问范围拒绝。

## 2. 契约、版本与样例

转换结构包含version、input（key固定为value，不可默认值）、expression、samples。目标Schema由已有字段决定，脚本不能自行修改。每个转换需1～5组含value与expected的精确样例；定义保存/检查、连接映射预览及任务构建/发布执行样例，实际值和预期JSON指纹不一致报 `TRANSFORM_SAMPLE_MISMATCH`。样例不是实时采集证据。

定义hash和revision包含表达式、Schema、样例；既有采集器发布证据仍要求与当前定义一致。连接转换随任务manifest冻结，修改后保存/发布新任务版本；旧运行使用其冻结定义。历史输出补采按选定版本重新映射并记录转换证据，历史完整输入补采沿用已转换快照。

`POST /api/v4/co/transforms/preview` 请求 `{transform,value,target}`，需要登录，严格解码，支持显式null。先验证全部样例，再预览value；成功返回value/evidence/target/formal_writes=0，失败返回字段位置、错误码和转换指纹。capabilities公布版本与主要预算。接口契约由`编排O0/co-o5-transforms.cjs`生成。

## 3. 语法、资源与权限

首版是纯JS表达式子集，不是任意脚本执行器：AST白名单验证后生成带逐节点预算检查的代码，不执行用户原始代码。只接受value、基础算术/比较/逻辑/条件表达式、固定属性/索引、有限数组和简单对象。

可调用String、Number、Boolean、parseInt、parseFloat，Math.abs/round/floor/ceil/min/max，trim/toLowerCase/toUpperCase/slice/substring/replace/split/join。replace只用字符串，不支持正则。禁止语句、函数/箭头、循环、赋值、new、动态索引或调用、原型/constructor、eval/Function、日期/随机数及外部访问。没有网络、文件、页面DOM、Go宿主对象、凭据和运行上下文权限。

| 预算 | 上限 |
| --- | --- |
| 表达式 | 8192字节、256 AST节点、24层 |
| 输入、每个中间值、结果 | 各8192字节JSON、16层、数组100项、对象30键 |
| 运行 | 每个值25ms、调用栈64，响应context取消 |
| 样例 | 1～5组，每组输入/预期各8192字节 |

拒绝非有限数字、undefined和认证字段。无循环、动态函数和扩容方法，逐节点检查限制中间扩容；这不是操作系统级硬内存沙箱。现有定义、页批次、分发计划、运行时间及存储总预算继续生效，较大值必须先用定位/提取缩小。大量字段/样例可能达到原有定义JSON大小上限。

## 4. 失败与可靠性

错误包括TRANSFORM_INVALID、TRANSFORM_INPUT_INVALID、TRANSFORM_EXECUTION_FAILED、TRANSFORM_TIMEOUT、TRANSFORM_CANCELLED、TRANSFORM_RESULT_INVALID、TRANSFORM_SAMPLE_MISMATCH。携带字段位置、转换版本及hash，不直接回显引擎异常中的用户源字符串。超预算或含认证字段的输入诊断省略before。

字段转换失败产生无效候选，保留FieldEvidence中的前后/错误，不写有效业务记录；字段证据随观察记录持久化。连接转换失败产生invalid映射行，不派发该下游输入。运行诊断从co_dispatch_plans.rows_json按展开序号读取转换证据，无需新列或迁移。试采、正式执行及重映射走同一实现；已有页面事务、租约、幂等派发、取消、Join/batch封口及访问范围检查仍生效。

工作台字段证据、任务映射预览、运行观察和分发诊断可展开前后值及指纹。只显示用户主动展开的诊断，不把所有JSON堆在表单主视图。
