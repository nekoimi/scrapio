# B07 首次数据与基础追溯

状态：2026-10-10 开发收尾，真实迁移/浏览器/页面验收保留发版。上游 B06，后续 C01～C04。本阶段完成只读浏览，不新增网站访问、数据重放、调度、导出或插件副作用。

## 用户路径

1. 发布后正式运行；已提交结果展示发布版本、实际文档/候选、写入决策和停止原因，以及一条本次真实保存的记录。
2. 点“查看全部数据”进入 `/app/data/:id`。新 `/app/data` 列出逻辑数据表、记录数、最近有效更新、来源方案；未变观察不会被当成有效更新。
3. 打开记录侧栏（表页 `?record=<id>`，或独立 `/app/records/:recordID`），查看当前字段、修订、来源观察和变化前后。
4. 从来源进入固定发布版本、`/app/runs/:id`、`/app/pages/:id`。运行详情解释拿到了什么、缺失步骤、为何结束和是否提交；页面展示来源网址、实际提取诊断、父列表和原始文档。

完成卡展示的是该运行提交时的值，记录侧栏展示最新值。全部未变仍是有效正式采集，保留观察；零候选/失败不伪造记录或成功卡。有限覆盖继续明确 limited。当前有界正式运行最多两页，连续分页接 C01。

## 读取接口

全部位于 `/api/v3`，沿用 `data/request_id` 和错误信封，均需登录。

| 接口 | 作用与分页 |
| --- | --- |
| `GET /tables` | 保持原 Schema/表字段，附带当前页统计，一次统计查询读取此页最多 50 张表 |
| `GET /tables/{table_id}/statistics` | 记录数、最近观察、最近创建/更新修订、来源方案 |
| `GET /tables/{table_id}/records` | 按不可变首次观察时间与 ID 降序，UUID 游标 |
| `GET /records/{record_id}` | 当前值、键、历史 Schema、精确逐字段 JSON 文本 |
| `GET /records/{record_id}/observations` | 来源输入、版本/运行/页面/角色，观察时间与 ID 降序 |
| `GET /records/{record_id}/revisions` | 修订号降序，前一修订和本修订值、变化字段、观察引用及当时 Schema |
| `GET /runs/{run_id}/pages` | 真实持久文档按序号升序，省略内容与重型提取诊断 |
| `GET /runs/{run_id}/attempts` | 真实运行尝试，最多 50 条；当前不自动重放，不返回租约/会话标识 |
| `GET /pages/{page_id}` | 页面诊断与版本/运行/方案/父列表；页面 ID 等于持久文档 ID |
| `GET /pages/{page_id}/attempts` | `scope=run`、该文档所属 attempt、运行尝试；当前没有页面级重试模型 |
| `GET /documents/{document_id}` | `offset` UTF-8 字节偏移、`limit` 默认 32768/范围 4～65536，返回 `next_offset/has_more` |

列表 `limit` 默认 25，范围 1～50。游标锚点必须在同表/记录/运行内，否则 404；参数无效 400。读取超时 408，存储异常 500。ID、数据库计数、Schema/修订号和来源时间在数据读取行中是字符串，避免 Go/JS 数字和时间隐式转换；运行 API 沿用 B06 类型。

`values_json`、`schema_json`、`fields_json` 等是 JSON 文本。`value_json` 始终保留数值字面量，展示文本时仅字符串值可解码，禁止把大整数先转成 JS number。字段按历史 Schema 命名；表格按表当前字段列排列，历史完整字段可在侧栏查看。

## 证据真实性与隔离

仅查询 `v22_data_tables`、`v22_table_*`、`v22_runs`、`v22_run_documents` 和新发布版本。旧资源、磁力、任务和下载数据保持原状，不投影/导入/混入新列表。每个入口经数据表或运行 owner 授权，来源观察同时约束运行 owner；分页锚点限定相同实体。

文档列表 `stored` 只表示存在内容。读取原始文档时校验全内容哈希与 UTF-8，返回 `available/unavailable/corrupt`；后两者不返回内容。清理后的空文档与未保留内容目前统一 unavailable，不臆测清理时间。页面诊断仍可保留，不能当成原始文档重新生成 HTML。

内容只作为 Vue 文本展示，不使用 `v-html` 或运行 iframe；来源 URL 是保存的证据，不重新请求。当前运行文档不包含截图，不展示截图占位作为有效证据。动作失败且没取到文档时不造页面，失败见运行摘要。父列表是同 run/attempt/step/list_page 的真实列表文档，父记录索引来自原诊断。

来源观察尚无单独来源记录索引列；当前能定位到真实文档和全部字段诊断，不能声称自动高亮精确来源行。运行写入摘要中保留的 `record_index` 仍用于 B06 完成结果。
