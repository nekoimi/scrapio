## 2. 本轮实际执行的短时检查

主平台根目录：

```text
node docs/项目文档v2.2/编排O0/build-contract.cjs
node docs/项目文档v2.2/编排O0/verify.cjs
git diff --check
```

verify使用已有web依赖，在不足数秒的离线过程中核对生成物无漂移、规划API/Schema引用与幂等标识、三份独立定义、图结构与必填映射拒绝、输入安全边界、当前页HTML/JSON预期，以及原型测试/试采/发布/取消确认/模拟正式结果/失败补采/单阶段切换。不是生产解释器测试，也没有运行真实数据库竞态。

浏览器仓库使用既有venv，临时将DEBUG设置为合法boolean（测试进程环境），运行：

```text
.venv/Scripts/python.exe -m unittest tests.test_v22_editor_sessions tests.test_v22_editor_commands tests.test_v22_state
```

结果：21项通过，unittest执行约0.21秒，命令总耗时不足2秒。全部使用FakeBrowser/FakeTab/桩；覆盖TTL/容量/创建关闭竞态、原动作回执不二次点击、未知结果缓存、敏感输入拒绝、DOM/帧及recheck边界。不证明真实context隔离或站点行为。

没有安装新依赖、改全局DEBUG、启动HTTP/浏览器/Manager、运行数据库迁移、完整构建或耗时全量测试。
