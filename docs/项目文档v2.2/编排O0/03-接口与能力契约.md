# O0 接口、能力与错误契约

日期：2026-10-13。CO-O0-07/09。可机读草案 [openapi.json](openapi.json) 的版本为co.contract.v1，O1采集器operation已标记 `implemented` 并挂载v4；O2+保留 `planned`。具体交付及真实验收边界见[O1实施记录](../独立采集器O1实施与验收记录.md)。

## 1. 新资源与身份

API `/api/v4`，新页面 `/app/co`。保持v1/v2/v3原路径及含义，不把旧collector run重新解释为task run。复用已验证的认证服务，除API专用触发token外均经会话身份授权；资源检查owner及父子关系。此轮不会向已有/capabilities宣称新能力已上线。

业务ID统一UUID字符串，时间UTC RFC3339，JSON键snake_case，分页limit默认20最大100、cursor不透明稳定。返回 `{data,request_id}`，失败 `{error:{code,message,retryable,location,details},request_id}`；location含task/stage/item/step/field按实际需要。未定义新对象直接作为数据库行返回。

## 2. 请求并发、幂等与异步

写草稿PUT包含expected_revision，冲突409返回当前revision；全定义PUT不省略依赖字段。POST创建/测试/检查/发布/触发/补采要求Idempotency-Key，作用域owner+operation+resource；规范请求指纹包含引用版本/输入/策略，重复同键同指纹查回原response，不同指纹409 IDEMPOTENCY_CONFLICT。

检查/测试/运行返回202或检查已计算时200，不阻塞整个网页流程。operation查询包含状态、原请求指纹、资源标识及error；GET /operations/by-key?operation=...&key=... 在响应丢失时查原请求。保留期内同请求不得重新执行，过期查询404明确说明过期，客户端不能当成原请求一定未发生。

发布引用check_id+expected_revision，服务再次校验definition/hash/schema/能力与证据。暂时成功的检查不能放行变化后的草稿。新运行引用task_version_id而非latest；cancel/pause/resume通过带expected_control_epoch和幂等键的control操作，避免迟到恢复覆盖新取消。

## 3. 资源分组

| 资源 | 主要行为 | 计划阶段 |
| --- | --- | --- |
| collectors、draft、samples、tests、publish-checks、versions | 独立输入/输出定义、测试和发布，无正式表绑定 | O1 |
| collector editor-sessions、session inspection/commands/receipts/frame | 所属新采集器的编辑会话，复用浏览器严格引用协议 | O1 |
| tasks、draft、input-checks、output-checks、publish-checks、versions | 输入源、图/映射、阶段表绑定、发布清单 | O2单阶段、O3连接 |
| task trials/runs、runs/stages/work-items/outputs/events/control | 冻结运行、工作项、结果/来源、暂停取消 | O2/O3 |
| run replay-checks/replays | 原输入/版本或显式新版本，从选定失败项/阶段补采 | O2原版本、O4扩展 |
| tables/records/schema/observations、source-checks/imports、schedules | 新数据域查询、输入物化、调度 | O2表、O4来源/计划 |
| operations、capabilities | 查原请求、结构版本和实际runtime能力 | 按已实现项公开 |

OpenAPI为O0完整资源骨架，稳定核心请求Schema包括CollectorDefinition、TaskDefinition、Bindings、触发、控制和错误。各实体响应的详细分页投影/资产响应在所属开发项补充，凡用BoundedObject标识的响应明确为待细化，不表示已冻结所有列或输入校验。

## 4. 能力协商

新控制面回复contracts可识别co.contract.v1/collector.v1/task.v1，interpreters包含co.interpreter.v1；runtime能力按字段分别声明available和reason，不因API文档存在置true。HTTP和浏览器分开，editor、commands、receipts、snapshot、state、stream、multi_sample及context isolation分别探测。

浏览器底层继续识别editor.v1、editor.auth.v1和已声明state扩展，不将新解释器版本塞进旧proto字段。新模型能力由控制面编排和适配决定；新context隔离需要在O1明确验证/扩展capability，不根据new_tab()猜测available。授权范围/凭据revision变化要求重建运行上下文，不能复用失效引用。

不能连接浏览器时独立HTTP测试仍可用；浏览器草稿可保存，浏览器测试/发布按真实required_capabilities阻断并提示具体服务/能力。动态输入不扩大origin范围，editor引用只限当前session/document。

## 5. 错误目录与下一步

| 代码 | 位置 | 客户端行为 |
| --- | --- | --- |
| INPUT_FIELD_INVALID / MAPPING_SOURCE_MISSING | 输入/连接目标字段 | 显示缺失/类型错误，访问前修复；不提示定位无效 |
| GRAPH_INVALID / VERSION_INCOMPATIBLE | 阶段/连接/版本 | 返回具体依赖和字段，调整后重检 |
| REVISION_CONFLICT / IDEMPOTENCY_CONFLICT | 操作 | 展示服务器revision或原请求指纹，不自动覆盖/重新执行 |
| CAPABILITY_UNAVAILABLE / CREDENTIAL_UNAVAILABLE | 采集器/阶段 | 解释服务或凭据引用，暂停共享错误项 |
| ORIGIN_OUT_OF_SCOPE / STALE_PAGE_STATE | 获取/页面 | 检查实际地址或重新只读查询，不自动扩大来源 |
| ACTION_RESULT_UNKNOWN | step/command_id | 查原回执，awaiting_confirmation，不自动重发 |
| OUTPUT_INVALID / OUTPUT_CHANGED_ON_REPLAY | 输出字段/身份 | 保留诊断，原工作项不覆盖已派发输出 |
| SCHEMA_CONFLICT / WRITE_CONFLICT | 表/绑定 | 重新预演版本和写入，禁止偷偷转换 |
| LEASE_LOST / RUN_CANCELLED | 工作项/运行 | 旧提交拒绝，不能继续写入 |
| INPUT_SNAPSHOT_REQUIRED / EVIDENCE_EXPIRED | 输入物化/来源 | 明确无法复现，显式确认新输入/运行 |
| BUDGET_LIMITED / CAPACITY_PAUSED | 运行/阶段 | 区分终态预算与可恢复积压，展示已处理范围 |

错误message中文可读、details有界且不返回凭据/网页敏感全文。SSE只传元数据事件，使用sequence+Last-Event-ID续读；断流继续GET原run，不新触发。网页画面用独立frame/stream能力，不塞进业务事件。

## 6. O1 契约落地补充

collector.v1 已实现输入绑定、当前页提取和有限分页，分页补 cursor_parameter/empty_marker；JSONPath仅支持 $, .key, [index], [*]。样例接口以当前测试evidence_id保存有限快照/预期，或显式导入input/snapshots/expected_outputs，不使用未实现的asset_ids。Operation返回id/resource/operation/status/result/error/time；具体TestResult、SessionView、SampleView/VersionView投影见OpenAPI。列表按created_at/id倒序游标，默认20、最多100。

新增测试列表/删除、样例删除、归档、会话关闭及测试原回执查询接口。/operations/by-key必须带operation、resource_id、key；创建采集器的resource_id为空。命令command_id等于幂等键，参数异参返回IDEMPOTENCY_CONFLICT；草稿保存返回REVISION_CONFLICT及latest_revision，确定输入错误返回INPUT_FIELD_INVALID。其他定义错误为INVALID_CONFIGURATION；浏览器未知动作为OUTCOME_UNCERTAIN，测试结果awaiting_confirmation；与上方规划错误目录的概念一致，以实际OpenAPI和实现为准。

独立会话使用editor.isolated.v1；协议不足阻断，真实context就绪仍需创建及现场验收。能力接口仅声明当前HTTP/浏览器/定义与测试范围，tasks_ready=false，不因O2文档存在报告可用。
